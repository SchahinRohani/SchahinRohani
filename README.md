### 🚧 Building

**`consumer`** · *private* · *closed alpha* \
A marketplace app that connects people, couriers and local businesses in real time —
one app, three sides, live on a map. Built solo and shipped to iOS, Android and web
from a single codebase.

<sub>Vue 3, Tauri 2, Bun, Postgres, ZeroMQ. Distributed backend with a custom
membership protocol and H3 geo-indexing.</sub>

*The goal: take it to high traffic and run the whole thing myself.*

**[`@scale.digital/astro-bun`](https://github.com/ScaliirDigital/root)** \
Lets Astro websites run on the Bun runtime — faster page delivery, less server cost.

<sub>ISR/SWR caching, Brotli/gzip pre-compression, automated releases with Sigstore
provenance.</sub>

**`@scale.digital/cli`** · *coming soon* \
Deploy a website to any cloud provider with one command, without paying platform
prices for it. 

Live preview: [test-preview.scaliir.digital](https://test-preview.scaliir.digital/en)

<sub>Framework agnostic by design. Built-in reverse proxy, automated deployments from
CI, preview environments per branch, TLS certificates handled for you. Astro and Qwik
supported today, more to follow.</sub>
